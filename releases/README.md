# Downloads

**Quer só jogar?** Abra https://auralisgame.vercel.app/ no navegador, sem instalar nada.

Para Windows 64 bits:

1. Baixe `AURALIS-Setup.exe` (menos de 1 MB; na página do arquivo, use *Download raw file*).
2. Execute. Se aparecer o aviso azul do Windows, clique em **Mais informações** e depois em **Executar assim mesmo** (o instalador ainda não é assinado digitalmente).
3. Siga as telas: o instalador baixa o jogo (cerca de 180 MB) da pasta `dados/` do repositório, confere cada parte e instala só para o seu usuário.

Quer conferir antes? O SHA-256 oficial está em `SHA256.txt`. No PowerShell: `Get-FileHash .\AURALIS-Setup.exe -Algorithm SHA256`.
